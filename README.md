Task Scheduler with Dependencies
This project simulates task scheduling with priorities and dependencies.

What it does
- Creates tasks with priority and optional dependency  
- Executes tasks in the correct order  
- Ensures dependencies are completed first  
- Detects circular dependencies  
- Shows execution order  
- Includes a web version with a Gantt chart  

How to run
pip install -r requirements.txt  
CLI:
python task_scheduler.py  
GUI:
python uischeduler.py  
Web:
streamlit run web_app.py  

Tech used-
Python  
Streamlit  
Tkinter  
Matplotlib
